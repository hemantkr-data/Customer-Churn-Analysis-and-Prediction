# 🚀 Customer Churn Analysis & Prediction

## 📌 Project Overview
This project focuses on analyzing customer churn behavior and predicting customers who are likely to churn using Machine Learning techniques.

The project includes:
- Data Cleaning
- Exploratory Data Analysis
- Machine Learning Prediction
- Interactive Power BI Dashboard
- Business Insights
